# 🛒 Building an E-Commerce API

This is a full-featured RESTful API for an E-Commerce platform built using **Flask**, **Flask-RESTX**, **SQLAlchemy**, and **MySQL**. It supports user management, product catalog, and order processing, and was designed with scalability and clean architecture in mind.

---

## Features

- User CRUD operations
- Product CRUD operations
- Orders with many-to-many product relationships
- Flask-RESTX API documentation at `/docs`
- Database models using SQLAlchemy
- MySQL database integration
- Modular Blueprint structure

---

## Tech Stack

- Python 3.11+
- Flask
- Flask-RESTX
- SQLAlchemy
- MySQL
- Marshmallow
- Flask-Migrate
- Flask-Caching & Flask-Limiter (if enabled)
